# Adzuna's terms constrain the product

needajob runs on Adzuna's free tier, which only permits non-commercial use; adding ads, paid features or lead generation requires an Adzuna licence first. The terms also require every displayed Job to carry an "Adzuna" label (at least 116×23px) linked to Adzuna, and outbound links to use each Job's `redirect_url`. We never show Adzuna's predicted salaries, which avoids the separate "Adzuna Jobsworth" attribution and keeps estimates from misleading juniors. If the Adzuna key is ever revoked, all harvested data must be deleted.
